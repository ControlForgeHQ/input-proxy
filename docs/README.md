# Documentation

Project documentation is organized by responsibility. Each document has one
authoritative purpose and should not duplicate information owned elsewhere.

- [Architecture](ARCHITECTURE.md) — runtime architecture, module
  responsibilities, lifecycle, and design rationale.
- [Engineering Principles](ENGINEERING.md) — engineering standards,
  contributor expectations, testing, reviews, and release practices.
- [D-Bus Interface](DBUS_INTERFACE.md) — public runtime-control interface,
  service naming, properties, methods, signals, and compatibility.
- [Roadmap](ROADMAP.md) — release goals, feature sequencing, and future scope.
- [AI Workflow](AI_WORKFLOW.md) — recommended workflow for AI-assisted
  contributions.
